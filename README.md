Fun laser shooter game (is a work in progress)
=
  
WASD to move  
1,2,3,4 for weapon selection  

1: MELEE
2: SHOTGUN
3: SMG
4: Pistol

R For reload  
E to turn off your lights (AI cannot see you then)  
Left Click to shoot  
Escape to show the mouse (click anywhere on screen to gain control again)
